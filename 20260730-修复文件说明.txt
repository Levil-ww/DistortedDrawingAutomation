一、预览图显示空白
================================================================================

预览图原本是空白的，根本原因有 4 个：

1. PSD 图层选择错误（最关键）
   文件: services/design_service.py (原第127行)
   原本固定使用 layers[0]（白色背景层）作为花纹，但该 PSD 的 layers[0] 是纯白底。
   修复后用 psd-tools 的 psd.composite() 直接渲染 PSD 完整合成图，保留所有
   图层叠加效果。

2. 缩放比例计算没有边界保护
   当 base 极小时（如 EPS 渲染失败），ratio = max_width / base.width 会变得
   极大，导致 pattern 被放大到画布外。修复后加上了：
   - base 尺寸异常时使用默认画布
   - pattern 等比缩放且用 min(width, height) 计算，确保贴入画布
   - 偏移坐标用 max(0, ...) 防止负数

3. 线程安全问题
   文件: gui/app.py (原第262行)
   _log() 直接在工作线程修改 log_text 引发竞争，导致 UI 更新不及时。
   修复后将所有 UI 操作通过 root.after(0, ...) 调度到主线程。

4. 错误诊断能力
   文件: engines/pillow_engine.py (原第44行)
   添加了 EPS 文件存在性/大小检查、错误日志、尺寸阈值判断，便于排查类似问题。

修复效果：预览图成功显示 PSD 的完整合成图（米色底 + 蔓生花 + 边框）。
后续发现此预览仅为 PSD 合成图，未与 CAD 图整合，由此引出任务二。

   - 当 PSD 与 EPS 方向不一致时，自动交换宽高

四、预览效果图与期望不一致（蒙版与对齐修复）
================================================================================

问题：预览图存在两大核心问题——EPS内部区域留白、边缘留白。

1. EPS内部区域留白
   文件: services/design_service.py (第220-282行)
   - 原因：_create_eps_mask 使用 cv2.RETR_EXTERNAL 只提取最外层轮廓，
     内部元素不参与蒙版，导致内部区域留白
   - 修复：重写 _create_eps_mask，使用 RETR_EXTERNAL 提取最外层轮廓后
     用 cv2.fillPoly 填充，再通过 MORPH_OPEN 平滑边缘
   - 新增 _create_eps_mask_fallback() 回退方案，使用 floodFill 洪水填充
     算法处理多个独立区域和嵌套区域

2. 边缘留白（cover模式修复）
   文件: processors/aligner.py (第70-78行)
   - 原因：原 cover 模式按检测到的边框 bounding box 缩放，导致边缘留白
   - 修复：cover 模式改为基于全图尺寸（base_img.width/height）计算缩放
   - 缩放系数: max(scale_x, scale_y) × 1.02，确保图案覆盖整张画布
   - contain 模式保持 min(scale_x, scale_y) × 0.98

3. CAD边框线叠加
   文件: services/design_service.py (第322-375行)
   - _compose_with_eps_mask() 新增 overlay_border 参数
   - 从 EPS 栅格化图像中提取深色像素（RGB < 120）作为边框线
   - 通过蒙版交集（is_dark & mask）精确定位边框区域
   - 将边框像素叠加到合成结果上，保证与 EPS 外轮廓弧度一致

4. 合成逻辑优化
   - 创建 RGBA 画布，先贴入图案再按蒙版裁剪
   - 蒙版区域显示图案，非蒙版区域填充白色
   - 最后叠加 CAD 边框线，形成完整最终效果

五、GUI界面按钮被遮挡
================================================================================

问题：生成预览、开始处理、重置参数等按钮在小窗口和最大化状态下不可见，

2. 左侧面板布局重构
   - 将左侧面板拆分为两部分：

           智能对齐、色彩调整、输出设置）
     下方: 按钮区通过 pack(side="bottom") 固定在面板底部，永远可见

3. 窗口尺寸优化
   - 初始窗口尺寸: 920x800 → 1100x800
   - 新增最小窗口尺寸: 900x680，防止窗口过小导致布局错乱

4. 鼠标滚轮滚动
   - 鼠标悬停在左侧面板时启用滚轮滚动，离开时自动解除
   - 兼容 Windows（MouseWheel）和 Linux（Button-4/Button-5）

5. 按钮样式微调
   - 按钮宽度从 12 调整为 10，减少横向占用
   - 新增 cursor="hand2" 鼠标手势提示
